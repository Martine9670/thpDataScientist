# Cryptocurrency Analysis

This project allows for the analysis of cryptocurrencies based on a list of cryptocurrency names and their respective values. The script is written in **Ruby** and uses data structures such as **arrays** and **hashes**, loops, and conditions to perform calculations and display interesting results about the cryptocurrencies.

---

## Features

The script executes several steps to analyze the cryptocurrencies:

1. **Transform values into numbers**  
   The initial values of the cryptocurrencies are converted into floating-point numbers to perform calculations.

2. **Associate each crypto with its value**  
   Each cryptocurrency name is paired with its value in a **hash** for easier search and data display.

3. **Display the cryptocurrencies with their value**  
   A list of cryptocurrencies is displayed along with their respective values.

4. **Display those with a value less than 6000**  
   The script filters and displays only the cryptocurrencies with a value less than **6000**.

5. **Find the most expensive crypto among those under 6000**  
   The script selects cryptocurrencies with a value under 6000 and determines the most expensive one among them.

# Journalist Handles Analysis

**Journalist Handles Analysis** is a Ruby project that allows performing several analyses on a list of **journalist handles** (for example, Twitter pseudonyms). The script makes use of data structures such as **arrays** and **hashes**, and utilizes **loops** and **conditions** to perform calculations and display useful information.

---

## Features

The script offers several analyses on journalist handles. Here is a list of the available features:

1. **Count the total number of handles in the array**  
   Calculates the number of elements in the array.

2. **Find the shortest handle in the list**  
   Finds and displays the handle with the smallest length (excluding the `@` symbol).

3. **Count handles with 5 characters (excluding the `@`)**  
   Displays how many handles have a length of 5 characters after removing the `@` symbol.

4. **Count handles starting with an uppercase letter after the `@`**  
   Identifies and displays how many handles start with an uppercase letter immediately after the `@` symbol.

5. **Sort the handles alphabetically**  
   Sorts and displays the handles in alphabetical order.

6. **Sort the handles by size (shortest first)**  
   Sorts and displays the handles based on their length, from shortest to longest.

7. **Find the position of a specific handle in the list**  
   Searches for and displays the position of a specific handle in the array.

8. **Handle distribution by size**  
   Displays a distribution of handles by size (how many handles have a specific length).
